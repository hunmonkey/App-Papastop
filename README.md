# PapaStop

PapaStop은 Windows에서 로컬 영상 또는 음성 파일의 소리를 분석해 SRT 자막을 만들고, 만든 자막을 다른 언어로 번역해 저장하는 데스크톱 앱입니다.

## 실행 방법

1. Python 3.10 이상을 설치합니다.
2. `run_papastop.bat`를 더블클릭합니다.
3. 앱이 열리면 `엔진` 탭에서 `엔진 설치`를 먼저 누릅니다.
4. `파일` 영역에서 영상 파일 하나를 고르거나, 동영상 폴더를 골라 목록에서 여러 파일을 체크합니다.
5. `자막 제작` 탭에서 필요하면 `권장 설정 적용`을 누릅니다. 여러 영상을 자막으로 만든 즉시 번역까지 한 번에 끝내려면 `자막 만든 뒤 자동 번역`을 체크하고 번역할 언어를 고른 뒤 `자막 만들기`를 누릅니다. (번역 원본 언어는 위 `원본 언어` 설정을 따르며, `자동 감지`면 소리에서 감지한 언어를 사용합니다.)
6. 작업을 멈추려면 `작업 중지`를 누릅니다. 현재 처리 중인 작은 단계가 끝난 뒤 멈춥니다.
7. `번역 저장` 탭에서 만들어진 SRT 파일을 선택한 뒤 원본 언어와 번역 언어를 고르고 `번역 자막 저장`을 누릅니다.
8. `자막 변환` 탭에서 SRT 자막을 VTT 또는 TXT 파일로 다른 이름 저장할 수 있습니다.

`run_papastop.bat`는 이 프로젝트 안에 `.venv`라는 전용 Python 실행 공간을 만듭니다. 쉽게 말해 PapaStop 전용 도구상자를 따로 만드는 방식이라, 다른 Python 작업과 섞일 가능성이 줄어듭니다.

## 엔진 미리 설치

앱을 열기 전에 엔진을 먼저 설치하고 싶다면 `install_engines.bat`를 더블클릭합니다. 설치 파일이 크기 때문에 처음에는 시간이 오래 걸릴 수 있습니다.

터미널에서 직접 실행하려면 아래 명령을 사용할 수 있습니다.

```powershell
.\run_papastop.ps1
```

## 수동 설치

앱의 `엔진 설치` 버튼이 실패하면 아래 명령으로 직접 설치할 수 있습니다.

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade -r requirements.txt
```

## Windows EXE 패키징

배포용 EXE를 만들려면 `build_package.bat`를 더블클릭합니다.

완료되면 아래 파일이 만들어집니다.

```text
dist\PapaStop\PapaStop.exe
```

배포할 때는 `dist\PapaStop` 폴더 전체를 ZIP으로 압축해서 전달합니다. `PapaStop.exe` 파일 하나만 따로 빼서 보내면 내부 엔진 파일을 찾지 못할 수 있습니다.

EXE 패키지 안에는 자막 제작/번역 엔진이 함께 들어갑니다. 그래서 EXE로 실행할 때 `엔진 설치` 버튼은 새로 설치하지 않고, 포함된 엔진을 확인하는 안내 역할을 합니다.

## 주요 엔진

- `faster-whisper`: 영상의 소리를 글자로 바꾸는 오픈소스 음성 인식 엔진입니다.
- `Argos Translate`: SRT 자막 문장을 다른 언어로 바꾸는 오픈소스 번역 엔진입니다.
- `imageio-ffmpeg`: 영상 안의 자막을 꺼내거나 영상 파일을 다룰 때 필요한 FFmpeg 실행 파일을 제공합니다.

## 저장 형식

- `SRT`: 일반 동영상 플레이어에서 많이 쓰는 자막 파일입니다.
- `VTT`: 웹 브라우저 영상 자막에서 자주 쓰는 형식입니다.
- `TXT`: 시간표시는 빼고 문장만 모아 둔 텍스트 파일입니다.

자막 생성 결과는 기본적으로 `동영상파일명.srt` 형태로 저장됩니다. 예를 들어 `sample.mp4`를 처리하면 `sample.srt`가 만들어집니다.

`자막 만든 뒤 자동 번역`을 켜면 번역 자막이 `동영상파일명.언어코드.srt` 형태로 함께 저장됩니다. 예를 들어 한국어로 번역하면 `sample.ko.srt`가 추가로 만들어집니다.

## 모델 선택 기준

- `tiny`: 빠르지만 정확도가 낮습니다.
- `base`: 첫 테스트에 적당합니다.
- `small`: 속도와 정확도의 균형이 좋습니다.
- `medium`, `large-v3`: 더 정확하지만 시간이 오래 걸리고 PC 사양을 더 많이 씁니다.

처음 쓰는 모델과 번역 언어팩은 자동으로 다운로드되므로 인터넷 연결이 필요합니다.

## PC 사양 활용

앱은 Windows의 CPU, RAM, 그래픽카드 정보를 읽어 화면에 표시합니다. `권장 설정 적용`을 누르면 NVIDIA 그래픽카드가 있는 PC에서는 GPU 중심 설정을, 없으면 CPU 중심 설정을 자동으로 넣습니다.
